### 3-2. 능력치 6종 = 엔진 데이터에 이미 있음 [확인: 코드 0xEC2E + 막대 픽셀 실측 일치]
- ROM `0x18836` 25팀x7x8B 의 앞 6바이트 = 막대 6줄: **s0 体力, s1 ぼうぎょ力, s2 すばやさ, s3 ジャンプ力, s4 シュート力, s5 キャッチ力**. 엔진 `server/data/teams.json` 의 `hp, def, spd, s3, pow, s5` 와 동일(analysis/data/teams_players.csv 에서 생성). 주의: 기존 이름 `s3_lob_or_arc`/`s5_timer` 는 표시상 의미가 점프력/캐치력.

## 5. 팀 소개 화면(에이스 얼굴·이름·칭호·능력치) — 미확정 [중요]
사용자 스크린샷: 팀 엠블럼·팀명·약칭 + 에이스 얼굴·이름 + 칭호(`도내 최강 체력치 보유 (12)` 등) + 6줄 게이지.
- 이번 캡처(전 모드 자동 진행)에서는 **이 화면을 찾지 못했다**. 스토리 stage1 흐름(sub2 제목 카드→sub3 장면→라인업→편성)에는 없음. 리그/특훈 일부 프레임이 렌더러 한계로 검게 나와 거기에 있을 가능성 [미확인]. 스토리 후반 스테이지에서만 나올 가능성도 있음. → 진입 조건·입력·사운드 모두 [미확인].
- ROM 근거로 확정된 것: 선수 이름(가나, 자체 문자코드) 전원 = `analysis/teams_names.json`(ROM 0x753FA+56*팀+8*선수). 능력치 6종은 §3-2. 팀명·약칭은 ROM 0x74F8E+12*팀. 능력치 라벨 히라가나판 문자열 `たいりょく・ぼうぎょりょく・すばやさ・ジャンプりょく・シュートりょく・キャッチりょく` 이 ROM 0xEA7A 에 있음(편성 화면은 한자 `体力` 그래픽이라 별개 쓰임 → 이 문자열을 쓰는 화면이 바로 팀 소개 후보 [추정]). 같은 영역에 확률 항목 라벨(シュートのスピード 등)도 있어 능력 상세 화면이 따로 있을 수 있음.
- **[추정] 에이스·칭호 숫자**: 에이스 = 팀 내 hp 최대(동률이면 뒤쪽 idx), 칭호 숫자 = floor(hp/9). 스크린샷 4팀과 일치: A.T りくおう とうま(idx0, hp115 → 12), TOK みたか はやと(idx0, 127 → 14), GRE レオ(idx6, 140 → 15; ライブラ idx5 와 동률이라 뒤쪽), 팀15 デービス(idx1, 144 → 16). 전 팀 값 `prematch.json#aceEstimate`(추정 표기). **ROM 표 근거 아님 → 구현 보류**.
- 칭호 등급 문구(도내 최강/전국 최강/세계 발군/세계 최강)의 팀별 대응과 한자 문구는 그래픽(텍스트 아님)이라 ROM 문자열로 못 뽑음. 팀 → 등급 표, 칭호 그래픽 위치는 [미확인].
- 일반 선수 이름 표시 화면(질문 4): **있음** [확인] — 라인업 VS(sub2/4)에 양 팀 7명 전원 얼굴+이름, 편성 화면은 hover 한 선수의 이름. 따라서 원작은 일반 선수 전원이 이름을 가진다(우리 `N번` 표시는 기존 team_names.json 의 일본어 이름을 한글 필터가 걸러서 생긴 것 - 17_player_names.md).

## 8. 2차 갱신 (추가 지시 반영)
### 8-1. 0xEA7A(히라가나 능력치 라벨) xref — 팀 소개 화면이 **아니다** [코드]
- ROM 0xEA1A 의 24개 포인터 표가 0xEA7A.. 문자열(たいりょく … シュートにあたるかくりつ, 24항목 = 선수 능력 24바이트)을 가리키고, 0xEA00 루틴이 `$E2A0`(항목 번호)로 그 표를 읽어 그린다. 호출 0xE662 ← 상태 핸들러 **0xE52C = $E600 0x34**(sub 4 에서 0xE5E0). 같은 핸들러가 문자열 `TEAM NO =`(0xE5D6)와 16진 값 표시(0xE696)를 쓴다 → **개발용 선수 파라미터(24항목) 뷰어/에디터**로 보이며 0x34 는 비스토리 모드 경기 종료 뒤 분기(0x56DC/0x3F8E)에서 도달하는 상태. 사용자 스크린샷의 에이스·칭호 화면과 무관. 도달 조건 전체는 [미추적].
- 스토리 sub2(제목 카드)는 VDP 윈도 레지스터 0(미사용), sub3 은 윈도 V=0x91(y>=136 하단 말풍선 창)로 **대사 장면**임을 윈도 합성 렌더로 확인(`t_pm_story_win.py`, `analysis/gfx/prematch/m0c_story_sub3_win.png`). 팀 소개(에이스·칭호) 화면은 스토리 stage1~라인업까지, 1PvsCOM, 1Pvs2P 경로에서 발견되지 않았다. 리그(0xB4 sub5~8)·특훈(0x94)·스토리 stage2+ 는 미확인.
- 에이스 선정·칭호 등급 표: ROM 에서 못 찾음 → **미해결**. `hp 최대, floor(hp/9)` 는 스크린샷 4팀 일치 추정일 뿐이라 구현에 쓰지 않았다(`prematch.json#aceEstimate` 는 참고용 추정 표기, 코드에서 읽지 않음).
