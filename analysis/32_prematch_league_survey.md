# 32. 경기 전 '팀 소개' 화면·리그·특훈 종류 — 이어 조사 (조사 전용)

조사일 2026-11-18. 소스·데이터·기존 문서는 고치지 않았다. 새로 만든 것은 이 문서와 `analysis/scripts/t32_step.py` 둘뿐이다.
20·28·29 문서와 `docs/HANDOFF.md` 의 결과를 전제로, 거기서 "미확인"으로 남긴 곳만 이어서 봤다.

근거 수준
- **[확정]** ROM 코드를 읽었고 자작 에뮬레이터(`analysis/scripts/m68k.py`)로 실제로 돌려 RAM·화면으로도 봤다. 디버그 플래그(`$E6A4`=1 poke)를 쓴 것은 "디버그"라고 적는다.
- **[판독]** 디스어셈블(`analysis/disasm_code.asm`)·ROM 표만 읽었다. 실행하지 않았다.
- **[추정]** 정황. **[미확인]** 보지 않았다.
- 소리는 큐 번호만 적었다(듣지 않음).

재현 (cwd = 프로젝트 루트)

28 문서와 다른 점(정정 후보, 28 문서는 고치지 않았다)
1. 스토리 서브 1 은 진입 컷이 아니라 **세계 지도**다. 진입 컷(가마쿠라·주인공…)은 **서브 13**(0x135CC)이고 はじめから 가 서브 13 으로 간다(0x119A0 `$E404`=0x0C). [확정(디버그 라운드 1) + 판독(일반 경로)]
2. SPECIAL TEAM 해금 비트(`$E500` bit0)는 "최종(15번째) 승리"가 아니라 **14번째 경기 승리 직후**에 서고, 같은 자리에서 세이브 창이 뜬다(저장 값 `01 0E 'DANPEI'`). 15번째 승리 뒤에는 세이브 없이 엔딩으로 간다. [확정(디버그 즉시 승리): `$E500` 0x80 → 0x81, `$E5A0` = `01 0E 44 41 4E 50 45 49`] / 15번째 승리 뒤 경로는 [판독 0x118EA]

## 1. 경기 전 '팀 소개' 화면

### 1-1. 스토리 서브상태 전수 (`$E600`=0x9C, 표 0x11840, 22개)

서브 전환은 0x10C78: `$E400 += 1 + $E404`. 디버그 라운드 선택(서브 17)의 분기 0x13F44 가 각 라운드의 진입 서브를 정한다.

15번째(최종) 경기는 라인업 VS 뒤 **편성 2장을 건너뛰고** 맞대면 대사로 간다(0x147E6 `$E448` ≠ 0 → `$E404`=2). [확정(디버그 r13: 서브 4 → 7)]

결론
- 스토리 22개 서브 어디에도 "에이스 얼굴 + 칭호 + 게이지" 화면은 없다. 리그·특훈·1PvsCOM·1Pvs2P 는 28 문서에서 전부 재생했다.
- 능력치 막대 루틴(0xEC2E)과 선수 이름 표(0x753FA)를 읽는 곳이 편성 화면과 디버그 뷰어뿐이라는 28 §6 의 판독과 맞는다.
- 스크린샷(도내 최강 체력치 보유 등)의 출처는 여전히 [미확인]. 원본을 받아야 대조할 수 있다.

표시 순서·타이밍
- 한꺼번에 그린 뒤 페이드 인(0x2562). 글자가 차례로 나오는 연출은 없다. [판독 + 확정(화면)]

## 2. 리그 (闘球リーグ)

### 2-1. 존재·진입 [확정, 28·29]

### 2-2. 29 문서 명세와 대조

| 항목 | 29 문서 | 이번 확인 | 수준 |
|---|---|---|---|
| 대진 | 총당. 한 쌍이 턴 수만큼. 카드는 아무 순서 | 변동 없음 | 확정(29) |
| 순위 | 승률(천분율 내림)만. 승점·득실 없음. 동률 같은 번호 | 변동 없음 | 확정(29) |

## 3. 특훈 종류

- 모드 0x94 의 서브 표(0x10E52)는 6개: 0 도입 대사 + 3지선다, 1 캐치 설명 대사(→ 경기 0x48), 2 캐치 완료 대사, 3 필살 설명 대사, 4 필살 완료 대사, 5 모드 메뉴로. [판독]
- 선택지 커서 `$C024`: 0 → `$E69C`=0(캐치), 1 → `$E69C`=3(필살, `$E404`=2), 2 → 나가기(0x10FA8). [판독 0x10F8A~0x10FF6] / 화면 [확정 28]
- `$E69C` 를 **쓰는** 곳은 전 ROM 에서 3곳: 0x10FCA(0), 0x10FDE(3), 0x3DA0(+1, 3 이 되면 완료). 나머지 참조 19곳은 읽기·비교다(쓰기 여부만 전수로 봤고, 읽는 쪽 각각의 내용은 29 문서가 해독한 곳 외에는 하나씩 읽지 않았다). [판독, 디스어셈블 `e69c` 전수 검색]
- 따라서 특훈은 **캐치(3단계)와 필살 슛 2종뿐**이고, 둘 다 이식돼 있다(HANDOFF §4-6~4-9). 숨은 3번째 종류는 없다.

특훈에서 아직 이식되지 않은 부분(종류가 아니라 연출)
| 항목 | ROM | 상태 |
|---|---|---|
| 도입 대사 + 3지선다 | 대사 포인터 표 0x753DE: 도입 0x76980, 캐치 선택 응답 0x76A04, 필살 선택 응답 0x76B00 | 미이식(로비에서 바로 시작) |
| 설명 대사 | 캐치 0x76A66, 필살 0x76BA6 | 미이식 |
| 완료 대사 | 캐치 0x76BDC, 필살 0x76C04 | 미이식(완료 카드로 대체) |
| 일시정지 `つづける / やめる` | `$E602`=0x14 | 대체(서버 일시정지 없음, 그만두기 확인 창) |
| 페이드 | 0x259E | 미이식 |
| 곡 0x98(도입) / 0x94(경기) | | 0x98 은 루프 미확정이라 무음(27 문서) |
| 필살 게이지 막대 그림 | 배너 ID 0x12 | 자작 그림(원작 미추출) |
- 대사 원문의 글자 단위 해독·번역은 이번에 하지 않았다(28 문서가 일부 디코드). [미확인]

| 순위 | 항목 | 난이도 | 서버 | 클라이언트 | 남은 조사 |
