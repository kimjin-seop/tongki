# 49. 스토리 대사 한국어 번역 검수 노트 (원작 대사 번역)

작성 2026-11-20, 송서사. 입력 `data/rom_derived/story_dialogue_jp.json`(ROM 원문, 비공개·수정 안 함). 산출 `server/data/story_dialogue_ko.json`(한국어만, 원문과 같은 키·인덱스 구조). 소스 코드·원문 JSON 은 고치지 않았다.
이 문서는 내부 검수용이라 일본어 원문을 인용한다. 배포 파일(`story_dialogue_ko.json`)에는 일본어가 없다.

## 1. 번역 범위

| 구분 | 원문 | 번역 | 비고 |
|---|---|---|---|
| 제목 카드 | 15장 | 15장 | `matches[k].title_ko.{number,subtitle}` |
| 경기 블록(경기 전·맞대면·승리 후·패배 후) | 88페이지 + 승리 후 이어지는 세그먼트 8페이지 = 96페이지 | 96페이지 | 3전 승리 뒤 `모두` 1페이지, 15전 승리 뒤 엄마 장면 7페이지 포함 |
| 7번째 승리 편지·졸업 | 7페이지 | 7페이지 | `extras[2]` |
| 15전 패배 블록 뒤 | 2페이지 | 2페이지 | `extras[3]`(쓰임 미측정) |
| 진입 컷 내레이션 | 13레코드 | 13레코드 | `story_cuts.json` 현행 한글 문장을 레코드 단위로 그대로 옮김 |
| 7번째 승리 내레이션 | 6레코드 | 6레코드 | `extras[1]` |
| 합계 | 105페이지 + 19레코드 + 제목 15 | 전부 | 원문에 없는 문장 추가 없음 |

구조 규칙(파일 `rules` 에도 기록)
- 한 페이지에 run 이 1개인 원문 구조를 그대로 따랐다(원문 105페이지 모두 run 1개).
- `lines_ko` 개수 = 원문 `lines` 개수. 둘째 줄부터 앞 공백 1칸은 원문과 같은 들여쓰기(「 다음 칸 맞춤). 화면이 공백을 접으면 들여쓰기만 사라지고 뜻은 같다.
- `speaker` 는 원문 id 를 그대로 둔다(타이핑음·입 슬롯 연결용). `nameKo` 는 이름 줄 표시용.
- 원문 `。`(뒤 49프레임 쉼) 자리에만 단독 `.` 을 둔다. 쉼 판정 = 앞뒤가 `.` 이 아니고 다음 글자가 공백·줄끝·`」`·끝인 `.`. 말줄임 `...`·더듬기 `이.기` 는 쉼이 아니다. 페이지별 쉼 개수는 원문 `puncPauses` 와 같게 맞췄다(29페이지, 쉼 2개짜리 3페이지).
- 타이핑음·입: 한글 음절 1자 = 가나 1자(48 §10-6 의 설계 선택). 모든 페이지에서 음절 수 ≤ 원문 가나 수.

## 8. 글자 수 점검

기준: 줄 길이 = 앞 들여쓰기 공백을 뺀 글자 수(「」·공백·부호 포함). 목표 14자 이하, 상한 16자. 진입 컷·7번째 승리 내레이션은 컷 화면 형식(가로 한 줄)이라 이 기준에서 뺐다(진입 컷은 기존 문장 그대로).
