# 불꽃의 계승 모드 — 로그라이트 게임 시스템 통합 기획서 (사용자 원문, 2026-11-19)

> 이 문서는 사용자가 제공한 기획 원문이다. 구현 기준이며 임의 수정 금지(차이·충돌은 별도 분석 문서에 기록하고 사용자에게 보고). 팀장 메모: 구현 시 "원작 엔진의 실제 처리 방식이 기획과 충돌하면 원작 동작 보존 우선"(§18 마지막 문단).

## 0. Claude Code 작업 지시

현재 개발 중인 메가드라이브 피구왕 통키 기반 웹게임에 신규 로그라이트 콘텐츠인 **「불꽃의 계승 모드」**를 추가한다.

이 문서는 신규 모드의 기획 및 구현 기준이다.

### 최우선 개발 원칙

1. 기존 스토리 모드, 컴퓨터 대전, 멀티플레이 및 기존 게임 시스템을 훼손하지 않는다.
2. 기존 전투 엔진, 캐릭터 데이터, 포메이션, 필살기, 애니메이션, 게임 물리 시스템을 최대한 재사용한다.
3. 신규 능력치 및 아이템 효과는 로그라이트 모드에서만 적용한다.
4. 원작 분석으로 확인된 능력치와 규칙을 기준으로 설계한다.
5. 원작에 존재하지 않는 능력치를 임의로 기본 능력치에 추가하지 않는다.
6. 모든 장비, 아티팩트, 소모품에는 고유한 16비트 픽셀아트 아이콘을 제공한다.
7. 아이템은 검, 마법 지팡이, 판타지 갑옷 등이 아닌 피구부 및 학교 스포츠물에 어울리는 물품으로 제작한다.
8. 먼저 기존 프로젝트를 분석하고, 현재 구조에 맞춰 확장한다.
9. 기존 프로젝트에 없는 기능을 구현된 것으로 가정하지 않는다.
10. 이 기획서의 초기 수치는 모두 데이터로 관리하여 향후 밸런스를 조절할 수 있도록 한다.

# 1. 모드 개요

## 1.1 모드 명칭

- 정식 명칭: 불꽃의 계승 모드
- 영문 내부 명칭: Legacy of Flames
- 시스템 식별자: `flame_legacy`

## 1.2 게임 콘셉트

7명의 선수를 중심으로 드림팀을 구성하고, 여러 피구팀을 상대로 연속 경기를 진행한다.

경기에서 승리하면 새로운 선수를 영입하거나 장비, 아티팩트, 소모품을 획득할 수 있다.

각 선수는 4개의 장비 슬롯을 보유하고, 팀 전체는 최대 3개의 공용 아티팩트를 장착한다.

아티팩트는 선수들의 필살기를 해금하거나 기존 포메이션을 강화한다.

패배하면 해당 도전에서 얻은 선수, 장비, 아티팩트 및 임시 강화가 초기화된다.

그러나 누적 보상인 불꽃코인을 통해 새로운 콘텐츠를 영구 해금하고 다음 도전을 준비할 수 있다.

## 1.3 참고할 게임 설계 방향

다음 성공적인 로그라이트 게임들의 시스템 설계 원칙을 참고하되, 기존 게임의 콘텐츠와 표현을 그대로 복제하지 않는다.

- Hades: 반복 도전, 영구 성장, 도전 중 빌드 형성
- Slay the Spire: 분기형 진행, 보상 선택, 유물 시너지
- Dead Cells: 장비 획득, 설계도 해금, 난이도 확장
- Rogue Legacy 2: 패배 이후에도 유지되는 성장
- Vampire Survivors: 재화를 이용한 직관적인 영구 업그레이드

이 시스템을 피구 경기, 선수 육성, 필살기, 포메이션에 맞게 재구성한다.

# 2. 원작 능력치 및 전투 시스템

## 2.1 기존 기본 능력치 8종

다음 능력치가 현재 확인된 기본 능력치의 전부다.

| ID | 능력치 | 원작 동작 |
|---|---|---|
| s0 | HP | 체력. 0 이하 시 아웃 |
| s1 | 방어력 | 피해 = max(0, 공 위력 - 방어력) |
| s2 | 이동속도 | 기저 s2<<12, 가속 s2<<7 |
| s3 | 점프력 | 초기 vz = 0x10000 + (s3<<12) |
| s4 | 공격력 | 기본 투구 위력, 점프·대시 보정 |
| s5 | 캐치 지속 | 캐치 자세 유지 프레임 |
| s6 | 투구 속도 | 공 속도 s6<<4 |
| s7 | 패스 속도 | 패스 공 속도 s7<<4 |

확인된 원작 규칙:

- 이동속도 상한: 3.0px/프레임
- 대시 점프 초기 속도 추가: 0x10000
- 공격력: s4에 점프 및 대시 중 각각 s4/4 보정
- 차지 공격 보정: 최대 +15
- s5=10일 때 캐치 타이머 9
- 투구 속도: 점프·대시 중 +0x100
- 투구 속도 차지 보정: 차지값<<4
- 필살기는 선수별 기존 2개
- 원작 필살기 종류: 32종
- 필살기 위력: 약 50~88
- 공중 투구 차지 13~15에서 B 버튼을 놓으면 필살기 발동
- 넉백 기본 수평 속도: 공 위력/16px/프레임
- 피격 수직 속도: 4.0
- 쓰러짐 시간: 60프레임
- 넉백은 방어력과 무관
- 공을 20초 이상 보유하면 강제 투구

기존 분석 주소:

- 방어력 계산: 0x853E
- 이동속도: 0x7FEA
- 점프: 0x7E66
- 투구 위력: 0x89AA
- 투구 속도: 0x7D0C
- 패스 속도: 0x72BC
- 필살기 종류: ROM 0x18732
- 필살기 위력: ROM 0x187FA

위 주소는 원작 분석 기준이다. 현재 웹게임 구현의 파일 또는 함수 위치와 동일하다고 가정하지 않는다.

## 2.2 로그라이트 신규 능력치 3종

기존 8개 이외에 다음 3개만 추가한다.

### R1. 넉백 저항

피격 시 수평 넉백을 감소시킨다.

예시:

`최종 수평 넉백 = 기본 넉백 × (1 - 넉백 저항률)`

- 기본값: 0%
- 초기 밸런스 상한: 60%
- 원작의 수직 넉백과 쓰러짐 시간은 별도 효과가 없는 한 유지

### R2. 캐치 후 밀림 감소

캐치 이후 선수의 이동 관성 또는 밀림을 빠르게 줄인다.

- 기본값: 0%
- 초기 상한: 60%
- 기존 캐치 성공 판정이나 캐치 지속 시간과는 별개
- 실제 적용 위치는 기존 캐치 및 이동 물리 코드 분석 후 결정

### R3. 쓰러짐 회복 단축

피격으로 쓰러진 뒤 행동 가능해지는 시간을 줄인다.

- 기본 쓰러짐: 60프레임
- 아이템으로 최대 24프레임 단축
- 최소 쓰러짐 시간: 36프레임

세 수치는 전부 로그라이트 전용 확장 능력치로 취급한다.

기본 능력치로 크리티컬 확률, 회피 확률, 마나, 필살기 게이지, 명중률 등을 추가하지 않는다.

특정 아이템이 조건부로 추가 피해 또는 행동 효과를 제공하는 것은 허용하지만 기본 능력치에 새 항목을 만드는 방식은 피한다.

# 3. 핵심 게임 진행

## 3.1 기본 구성

- 기본 선수 구성: 7명
- 선수별 장비 슬롯: 4개
- 팀 전체 장비 슬롯: 최대 28개
- 공용 아티팩트 슬롯: 3개
- 기본 도전: 총 3개 구간
- 기본 경기: 총 12경기
- 구간별 보스 경기: 1회
- 전체 보스 경기: 3회

선수 7명은 기존 게임의 선수 및 포메이션 데이터를 기준으로 한다.

실제 경기 참가 인원과 교체 규칙은 기존 엔진을 분석해 연동한다.

## 3.2 진행 방식

1. 불꽃의 계승 모드 진입
2. 영구 성장 효과 확인
3. 초기 선수 구성
4. 첫 번째 상대 팀 선택
5. 경기 진행
6. 승리 시 보상 선택
7. 다음 노드 선택
8. 장비 장착 및 강화
9. 포메이션 및 아티팩트 조정
10. 다음 경기 진행
11. 보스 격파
12. 최종 우승 또는 패배
13. 불꽃코인 정산
14. 영구 성장 및 콘텐츠 해금
15. 새로운 도전 시작

## 3.3 진행 지도

기존 일반적인 토너먼트 방식에 로그라이트 분기형 지도를 결합한다.

노드 종류:

- 일반 경기: 표준 보상
- 강팀 경기: 높은 난이도와 높은 보상
- 보스 경기: 구간 최종 상대
- 장비 상점: 장비 및 소모품 구매
- 특훈장: 선수 강화
- 휴식실: HP 회복
- 선수 영입: 신규 선수 선택
- 특별 이벤트: 무작위 보상 또는 위험 선택

한 구간의 진행 예시:

일반 경기 → 보상 선택 → 상점 또는 특훈 → 강팀 경기 → 휴식 또는 영입 → 보스 경기

구간마다 상대 팀과 보상, 이벤트가 달라진다.

## 3.4 패배 규칙

기본 규칙은 경기 1회 패배 시 해당 도전 종료다.

도전 종료 시 초기화되는 항목:

- 도전 중 영입한 선수
- 선수별 장비
- 공용 아티팩트
- 장비 강화 수치
- 임시 특훈 효과
- 도전 내 상점 재화
- 보유 소모품
- 해금 아티팩트를 통해 활성화했던 필살기

영구 보존되는 항목:

- 불꽃코인
- 영구 성장 구매 내역
- 해금한 선수
- 해금한 장비 및 아티팩트 도감
- 새로운 난이도
- 업적 및 최고 기록

영구 해금은 원칙적으로 해당 아이템이 다음 도전의 보상 목록에 등장하도록 만드는 것이다.

영구 해금되었다고 장비 또는 아티팩트가 자동 지급되는 것은 아니다.

장비 1개 계승 같은 특별한 시스템은 초기 버전에서 제외하고 추후 별도 기능으로 검토한다.

# 4. 선수별 장비 시스템

## 4.1 기본 구조

모든 선수는 장비 4개를 착용할 수 있다.

1. 머리띠
2. 장갑
3. 가슴보호대
4. 복장

같은 장비를 여러 선수가 동시에 착용할 수는 없다.

장비는 도전 중에만 획득하고 사용한다.

장비별로 다음 정보를 보유한다.

- 아이템 ID
- 아이템 이름
- 장비 분류
- 희귀도
- 기본 능력치
- 고유 특수효과
- 강화 레벨
- 포메이션 태그
- 필살기 태그
- 아이콘 파일명
- 획득 출처
- 판매 가격

## 4.2 장비 등급

| 등급 | 색상 | 기본 특징 |
|---|---|---|
| 일반 | 회색 | 기본 능력치 중심 |
| 희귀 | 파랑 | 1~2개 능력치 강화 |
| 영웅 | 보라 | 특수효과 및 시너지 |
| 전설 | 금색 | 빌드의 핵심 효과 |

등급별 기본 보상 등장 비율 예시:

- 일반: 55%
- 희귀: 30%
- 영웅: 12%
- 전설: 3%

진행 구간, 난이도, 강팀 경기, 영구 성장에 따라 조정한다.

고등급 장비는 단순 능력치 상승뿐 아니라 새로운 전략을 제공해야 한다.

모든 아이템에는 각각 고유한 픽셀아트 아이콘을 제작한다.

# 6. 장비 강화 시스템

## 6.1 강화 방식

각 장비는 도전 중 최대 +3까지 강화할 수 있다.

강화는 특훈장 또는 특정 상점에서 진행한다.

기본 강화 비용:

| 강화 | 경기 포인트 | 효과 |
|---|---:|---|
| +1 | 60 | 기본 능력치 보너스 약 20% 증가 |
| +2 | 140 | 기본 능력치 보너스 약 40% 증가 |
| +3 | 260 | 기본 능력치 보너스 약 60% 증가 |

초기 버전은 강화 실패를 적용하지 않는다.

강화에 따른 능력치 보너스는 정수 반올림 기준을 통일한다.

장비 고유 특수효과는 강화하더라도 별도로 지정되지 않은 경우 유지한다.

## 6.2 장비 합성

같은 장비 3개를 재료로 사용하여 다음 등급의 장비를 획득하는 기능을 추후 확장한다.

초기 버전에서는 장비 합성보다 강화와 교체 시스템을 우선 구현한다.

# 7. 팀 공용 아티팩트 시스템

## 7.1 기본 구조

팀은 최대 3개의 아티팩트를 장착할 수 있다.

아티팩트는 선수 개인 장비가 아닌 팀 전체에 적용되는 특별한 피구용 아이템이다.

아티팩트 역할:

1. 필살기 해금
2. 필살기 강화
3. 기존 포메이션 강화
4. 팀 전체 능력치 강화
5. 특정 전술 활성화
6. 아티팩트 간 조합 효과

아티팩트는 일반 장비보다 더 강력한 효과를 가지며, 경기 진행 중 제한적으로 획득한다.

## 7.2 필살기 해금 원칙

불꽃의 계승 모드에서는 처음부터 필살기를 사용할 수 없다.

통키를 포함한 모든 선수는 기본적으로 일반 투구만 가능하다.

필살기 해금 아티팩트를 장착하면 특정 필살기를 사용할 수 있게 된다.

단, 기존 필살기 시스템은 유지한다.

- 기존 필살기 shotId를 사용한다.
- 기존 필살기 애니메이션을 재사용한다.
- 기존 32종 데이터를 활용한다.
- 기존 공중 투구 및 차지 발동 규칙을 유지한다.
- 필살기 게이지를 새로 만들지 않는다.
- 기존 필살기 사용을 아티팩트가 허용하거나 제한하는 방식으로 구현한다.

각 선수는 필살기 장착 슬롯 2개를 유지한다.

활성화된 아티팩트가 제공하는 기술 목록 중 해당 선수에게 적용 가능한 기술을 최대 2개 선택하게 한다.

필살기 종류와 shotId는 반드시 기존 소스에서 확인하여 매핑한다.

기존 엔진에 없는 슛을 실제 구현된 것처럼 등록해서는 안 된다.

# 8. 포메이션 시너지 시스템

## 8.1 기본 원칙

기존 게임의 포메이션 시스템을 그대로 활용한다.

새로운 포메이션 시스템을 별도로 복제하지 않는다.

아티팩트는 기존 포메이션에 추가적인 능력치 또는 전술 효과를 부여한다.

## 8.2 포메이션 분류

기존 포메이션을 분석하여 다음 전술 태그와 연결한다.

- 공격형
- 수비형
- 속공형
- 연계형
- 고공형
- 균형형

현재 구현되지 않은 분류가 있다면 기존 포메이션의 특징을 바탕으로 연결하거나 별도 설계 대상으로 분리한다.

## 8.3 강화 예시

### 공격형 포메이션

조건:

- 공격형 포메이션 사용
- 불꽃 훈련공 장착
- 돌격 작전판 장착

효과:

- 공격력 +3
- 불꽃 계열 필살기 위력 +10%
- 공격 중심의 팀 빌드 완성

### 수비형 포메이션

조건:

- 수비형 포메이션 사용
- 철벽 작전보드 장착
- 철벽 팀 배지 장착

효과:

- 방어력 +2
- 넉백 저항 +15%
- 캐치 이후 반격을 중심으로 운영

### 속공형 포메이션

조건:

- 속공형 포메이션 사용
- 속공 호각 장착
- 질풍의 응원 깃발 장착

효과:

- 이동속도 +1
- 투구 속도 +2
- 빠른 패스와 공격 전환에 유리

## 8.4 공용 아티팩트 시너지 규칙

아티팩트는 최대 3개까지 장착할 수 있으므로, 강력한 조합을 제한된 슬롯 안에서 완성하도록 설계한다.

특정 조합을 만족하면 추가 시너지를 부여한다.

예시:

- 불꽃 훈련공 + 돌격 작전판: 불꽃 필살기 강화
- 철벽 작전보드 + 캐치 특훈 교본: 캐치 후 반격 강화
- 속공 호각 + 팀워크 응원 깃발: 패스 후 첫 투구 속도 강화
- 주장 완장 + 연계 작전노트: 주장 중심 패스 연계 강화

시너지 효과는 별도의 데이터 테이블에서 관리한다.

아티팩트 간 조합이 있다고 해서 모든 조합에 신규 애니메이션을 요구하지 않는다.

초기 버전은 기존 필살기 및 수치 효과를 활용하고, 필살기 융합 애니메이션은 추후 확장 대상으로 둔다.

# 10. 불꽃코인 및 경제 시스템

## 10.1 재화 구분

### 불꽃코인

영구 재화다.

용도:

- 영구 성장 구매
- 신규 선수 해금
- 신규 장비 해금
- 아티팩트 해금
- 시작 보상 선택지 확장
- 신규 도전 난이도 해금

도전에서 패배해도 유지한다.

### 경기 포인트

도전 내에서만 사용하는 임시 재화다.

용도:

- 도전 중 장비 구매
- 소모품 구매
- 장비 강화
- 이벤트 비용 지불

도전 종료 시 초기화한다.

## 10.2 불꽃코인 지급 기준

초기 제안 수치:

| 조건 | 불꽃코인 |
|---|---:|
| 일반 경기 승리 | 20 |
| 강팀 경기 승리 | 40 |
| 보스 경기 승리 | 80 |
| 최종 우승 | 추가 200 |
| 첫 우승 보너스 | 추가 300 |

경기 보상은 도전 종료 시 한 번 정산한다.

정산된 불꽃코인은 영구 보존한다.

경기 포인트는 별도 보상 테이블을 사용하며 전투 내 상점 경제와 연결한다.

## 10.3 불꽃코인 영구 성장

### A. 기본 훈련

| 강화 | 단계 | 효과 | 비용 |
|---|---|---|---|
| 기초 체력 훈련 | 3 | 시작 선수 HP 단계별 +2 | 100 / 200 / 350 |
| 기본 수비 훈련 | 2 | 시작 선수 방어력 단계별 +1 | 250 / 500 |
| 투구 훈련 | 2 | 시작 선수 공격력 단계별 +1 | 250 / 500 |
| 캐치 훈련 | 2 | 시작 선수 캐치 지속 단계별 +1 | 200 / 400 |

영구 능력치 상승은 제한적으로 제공한다.

### B. 출발 준비

| 강화 | 최대 단계 | 효과 |
|---|---|---|
| 초기 지원금 | 3 | 시작 경기 포인트 증가 |
| 장비 보급 | 2 | 시작 장비 선택지 추가 |
| 전술 연구 | 2 | 시작 아티팩트 후보 선택권 제공 |
| 스카우트 인맥 | 3 | 선수 영입 후보 증가 |
| 상점 확장 | 3 | 상점 상품 선택지 증가 |
| 특훈 효율 | 2 | 장비 강화 비용 감소 |
| 보상 분석 | 2 | 경기 보상 재선택 횟수 증가 |

### C. 콘텐츠 해금

- 신규 선수 해금
- 전설 장비 설계도 해금
- 신규 아티팩트 해금
- 새로운 경기 이벤트 해금
- 새로운 상대 팀 해금
- 고난도 도전 해금

특정 콘텐츠는 코인 구매와 업적 달성을 함께 요구할 수 있다.

## 10.4 밸런스 원칙

불꽃코인으로 모든 능력치를 무제한 강화할 수 없어야 한다.

영구 성장의 핵심은 다음 도전의 선택지를 넓히는 것이다.

숙련된 플레이어는 영구 성장이 낮아도 충분히 클리어할 수 있어야 한다.

# 11. 선수 영입 및 육성

## 11.1 선수 영입

경기 승리 후 보상으로 새로운 선수를 영입할 수 있다.

영입 후보는 기존 게임에 구현된 선수 데이터를 사용한다.

선수별로 다음 항목을 표시한다.

- 이름
- 팀
- HP
- 방어력
- 이동속도
- 점프력
- 공격력
- 캐치 지속
- 투구 속도
- 패스 속도
- 기본 필살기 2종
- 현재 착용 장비
- 추천 전술 역할

영입한 선수는 도전 종료 시 초기화된다.

영구 해금된 선수는 이후 도전의 시작 선수 또는 영입 후보 목록에 포함될 수 있다.

## 11.2 선수 육성

도전 중 특훈 이벤트로 기본 능력치를 강화할 수 있다.

특훈 예시:

- 체력 훈련: HP 증가
- 수비 훈련: 방어력 증가
- 달리기 훈련: 이동속도 증가
- 점프 훈련: 점프력 증가
- 투구 훈련: 공격력 증가
- 캐치 훈련: 캐치 지속 증가
- 속구 훈련: 투구 속도 증가
- 패스 훈련: 패스 속도 증가
- 균형 훈련: 넉백 저항 증가
- 안정 훈련: 캐치 후 밀림 감소
- 회복 훈련: 쓰러짐 회복 단축

## 11.3 선수 역할

선수 역할은 별도의 기본 능력치가 아니다.

기존 능력치와 장비를 바탕으로 추천하는 전술 분류다.

예시:

- 공격형 에이스
- 수비형 선수
- 캐치 전문 선수
- 속공형 선수
- 고공 공격형 선수
- 패스 연계형 선수
- 균형형 선수

선수 능력치를 바꾸면 추천 역할도 달라질 수 있다.

# 13. 아이템 아이콘 제작 기획

## 13.1 절대 원칙

모든 아이템에는 각각 다른 고유 아이콘을 제공한다.

초기 아이콘 제작 목표:

- 선수 장비 40종
- 공용 아티팩트 30종
- 소모품 20종

총 90개의 개별 아이템 아이콘을 제작한다.

동일한 아이콘의 색상만 변경하여 서로 다른 아이템을 표현하는 방식은 지양한다.

## 13.2 픽셀아트 스타일

- 16비트 메가드라이브풍
- 일본 열혈 스포츠 게임 분위기
- 밝고 명확한 색상
- 진한 픽셀 외곽선
- 강한 명암 대비
- 물건의 형태가 즉시 구분되는 실루엣
- 지나치게 사실적인 묘사 금지
- 현대적인 3D 렌더링 금지
- 판타지 RPG 아이템처럼 제작 금지

게임 UI와 자연스럽게 어울리도록 한다.

## 13.3 기술 규격

- 기본 아이콘: 32×32px
- 필요한 경우 고해상도 원본을 제작한 후 픽셀아트 규격에 맞춰 정리
- PNG 사용
- 투명 배경
- 색상 팔레트 일관성 유지
- CSS 이미지 렌더링은 `pixelated`
- 희귀도 테두리는 아이콘 파일 외부 UI에서 처리

모든 아이콘을 자동 검사하여 누락된 파일, 잘못된 경로, 중복 ID를 검출한다.

이미지 생성 도구가 없는 경우 우선 아이콘 상세 제작 명세와 리소스 목록을 만들고, 실제 아이콘 제작과 검증은 별도 단계로 처리한다.

최종 결과물에 임시 이모지나 동일한 기본 아이콘을 그대로 남기지 않는다.

# 14. 아이템 능력치 및 시너지 계산

## 14.1 능력치 계산 순서

다음 계산 순서를 기본안으로 사용한다.

1. 선수 기본 능력치
2. 영구 성장 보너스
3. 도전 중 특훈 보너스
4. 선수별 장비 보너스
5. 팀 공용 아티팩트 보너스
6. 현재 포메이션 보너스
7. 아티팩트 조합 시너지
8. 소모품 임시 효과
9. 최종 상한 및 하한 처리

기존 엔진에서 이미 적용 중인 버프가 있다면 중복 계산하지 않는다.

## 14.2 계산 규칙

- 기존 8개 능력치는 원칙적으로 정수로 관리한다.
- 최종 계산의 반올림 규칙을 통일한다.
- 비율 수치는 내부적으로 일관된 단위를 사용한다.
- 이동속도 상한은 기존 원작 규칙을 유지한다.
- 넉백 저항은 설정된 최대 상한을 적용한다.
- 쓰러짐 시간은 최소 36프레임 이상으로 제한한다.
- 장비 효과 제거 시 원래 능력치로 정확히 복구되어야 한다.

## 14.3 전투 밸런스

특히 다음 항목을 검증해야 한다.

- 방어력이 높아져 피해가 0으로 고정되는 문제
- 이동속도 상한 때문에 장비 효과가 무효가 되는 문제
- 공격력과 필살기 위력이 중복 증가하는 문제
- 넉백 저항이 지나치게 높아 경기의 타격감을 훼손하는 문제
- 쓰러짐 회복을 너무 빠르게 하여 피격 페널티가 사라지는 문제
- 7명 전원의 시너지가 중첩되어 전투가 지나치게 쉬워지는 문제

# 17. 필수 테스트 항목

다음 조건을 모두 확인한다.

1. 스토리 모드에서는 기존 필살기와 능력치가 변경되지 않는다.
2. 불꽃의 계승 모드는 필살기가 잠긴 상태로 시작한다.
3. 기술 해금 아티팩트를 장착하면 해당 필살기가 활성화된다.
4. 해금 아티팩트를 해제하면 해당 필살기는 다시 비활성화된다.
5. 선수별 4개 장비 슬롯이 독립적으로 작동한다.
6. 서로 다른 선수에게 동일 장비 인스턴스가 중복 장착되지 않는다.
7. 장비 강화 효과가 정확하게 적용된다.
8. 장비 제거 시 수치가 원상복구된다.
9. 아티팩트는 최대 3개만 장착된다.
10. 포메이션 변경 시 모든 시너지 효과를 다시 계산한다.
11. 선수 7명의 최종 능력치가 정확하게 표시된다.
12. 넉백 저항이 피격 이동량에 정상 적용된다.
13. 캐치 후 밀림 감소가 실제 캐치 이후 이동에 반영된다.
14. 쓰러짐 회복 시간이 지정된 범위에서 변경된다.
15. 이동속도 상한을 초과하지 않는다.
16. 공 보유 20초 제한이 유지된다.
17. 패배 후 도전 중 획득한 장비와 아티팩트가 초기화된다.
18. 패배 후 불꽃코인과 영구 해금은 유지된다.
19. 저장 후 재접속 시 현재 도전을 정상적으로 복구한다.
20. 모든 아이템 ID에 대응하는 개별 아이콘 파일이 존재한다.
21. 게임 패드 또는 키보드 조작이 기존 인터페이스와 충돌하지 않는다.
22. 기존 스토리 및 일반 대전 기능에 회귀 오류가 발생하지 않는다.

# 18. 최종 개발 요청

Claude Code는 다음 순서를 준수한다.

**첫째**, 현재 프로젝트의 구조를 실제로 분석한다.

**둘째**, 이 기획서와 기존 코드 사이의 차이점을 정리한다.

**셋째**, 재사용 가능한 기존 시스템과 신규 개발이 필요한 시스템을 구분한다.

**넷째**, 신규 시스템을 독립적인 모듈로 설계한다.

**다섯째**, 위 구현 순서에 따라 기능을 개발한다.

**여섯째**, 각 기능 완료 시 기존 모드에 영향을 주지 않았는지 검증한다.

**일곱째**, 모든 아이템에 고유 픽셀아트 아이콘을 연결한다.

**여덟째**, 실제 동작하는 기능과 미구현 기능을 구분해 결과를 보고한다.

최종적으로 다음 목표를 달성해야 한다.

> 불꽃의 계승 모드는 원작 피구 게임의 조작감과 경기 구조를 유지하면서, 7명의 선수를 육성하고 장비를 수집하며, 아티팩트로 필살기와 포메이션을 강화하고, 패배 후에도 영구 성장하는 독립적인 로그라이트 게임 모드로 완성한다.

기획에 포함된 모든 초기 수치와 확률은 밸런싱 가능한 데이터로 관리하며, 기존 원작 엔진의 실제 처리 방식이 기획과 충돌할 경우 원작 동작의 보존을 우선한다.
