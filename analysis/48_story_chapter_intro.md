# 48. 스토리 챕터 진입 연출(제목 카드·대사 장면·초상 입 움직임·타이핑음·BGM)과 캠페인 전체 BGM — 원작 대조와 구현 계획

조사일 2026-11-20. 읽기 전용 조사. 소스·데이터·기존 문서는 고치지 않았다. 새로 만든 것은 이 문서뿐이다(임시 스크립트·캡처는 프로젝트 밖 scratchpad).

근거 수준
- **[확정]** ROM 을 직접 디코드했거나 우리 앱을 임시 서버 + headless Edge 로 실제로 돌려 확인.
- **[판독]** `analysis/disasm_code.asm` 코드·ROM 표만 읽음(실행 안 함).
- **[기존]** 이전 문서(12·20·27·28·32·35)의 결과를 그대로 인용.
- **[미측정]** 원작 실행으로 재야 하는 값. 추측으로 채우지 않았다.
- 소리는 듣지 않았다. 곡·효과음은 명령 번호와 시점만이다.

확정된 사용자 요구(2026-11-20, 팀장 전달)
1. 챕터를 누르면 원작처럼 `第N戦 「부제」` 제목 카드가 나온다.
2. 이어서 원작의 대사 장면: 배경 그림 + 두 사람 초상 + 이름 줄 + 대사 타이핑. **말하는 사람 초상의 입이 움직인다.**
3. 그 장면의 원작 BGM 과 대사 타이핑 효과음을 원작대로 낸다.
4. 프롤로그 마지막의 `제1전` 카드는 프롤로그에서 뺀다(챕터 진입 연출로 옮김).
5. 하단 대화창은 **우리 기존 초록 창을 그대로 쓴다**(원작 창 복제 안 함). 배경·초상(입)·타이핑·BGM·제목 카드는 원작 방식.
6. 캠페인 전체에서 비어 있는 BGM 을 원작과 같게 채운다.

### 2-1. 제목 카드 동작 (서브 2, 0x11C94) [판독 + 기존 12 실측]
- 진입: 0x91 → 화면 지움 → 글자 타일 `0x6E1EE`(압축)를 VRAM 0xDC 에 → 경기 k 의 맵 포인터 표 `0x743FE[k]`(Enigma), 폭 표 `0x7443A[k]`, VRAM 위치 표 `0x7444A[k]`.

### 10-3. 초상·입 움직임 측정 [확정: 원작 실행]
- 초상은 BG 가 아니라 **스프라이트**다. 상자 좌상단 왼쪽(통키) (16,160), 오른쪽(상대) (264,160), 각 40x40 = 32x32 + 8x32 + 32x8 + 8x8 스프라이트 4장. 통키 팔레트 0, 상대 팔레트 1. 통키 초상은 15경기 모두 같은 그림.
- **입 = 8x8 스프라이트 1장 오버레이**. 애니 표 0x72DCA, 상대 애니 번호 = 2(k+1)(k=0~13), 15전 초상 교체 앞 0x1C(캐서린, 14전과 같은 애니)·뒤 0x1E, 통키 0.
- **입 애니: 2칸, 칸당 5프레임(대기 바이트 4), 한 주기 10프레임.** 객체를 켜는 프레임에 1틱 진행해 칸1(`mouthA`, 입 벌림)부터 보인다(mouthA 5f → mouthB 5f → …). 객체 꺼짐 = `closed`(바탕 4장만). 16명 중 15명은 mouthB 가 closed 와 같은 그림이고, 13전 상대(애니 0x1A)만 mouthA·mouthB 둘 다 바탕과 다르다(`portraits.json` evidence `equalsClosed`). 그래서 시트는 인물마다 closed·mouthA·mouthB 3칸으로 두었다.
- 가나가 아닌 글자·`」` 앞·페이지 끝에서 객체를 끄면 오버레이가 사라져 닫힘이 되고, 다시 켤 때 **애니 위상이 이어진다**(리셋 없음: 재개 직후 (칸, 남은 대기)가 (1,4)·(1,0)·(1,2)·(0,3)·(0,1) 등 제각각, 끊긴 구간 1~5프레임 140회). 끊기지 않은 구간은 5프레임 422회.
- **통키 눈 깜빡임**(새로 찾음): 객체 0x12C(`$C780`, 처리 0x116BE), 통키가 말하지 않을 때만. blink1(0x72FE2, 반쯤 감음) 3f → blink2(0x72FEA, 감음) 3f → 평소(0x72FDA = closed 와 같음), 다음 깜빡임까지 난수 간격(대기 = 난수 하위 바이트, 8 미만은 8; 실측 3~139f). 상대 초상은 깜빡이지 않는다.
- **정정: §1·§2-2·§6 #3 의 "15전 전용 배경 0x60FAE" 는 배경이 아니라 오른쪽 초상 교체다.** 0x60FAE 는 VRAM 0x4C0(상대 초상 자리), 0x6385A 는 0x51E(입 자리)로 들어가고, 교체 전후 화면에서 창 위 영역 차이 0픽셀, 바뀐 곳은 (265~302, 161~198) 초상 상자뿐이다. 코트 배경은 14전과 같은 스테이지 6 그대로 → **따로 뽑을 배경 그림은 없다.** 교체 뒤 초상 = 시트의 `taiga_15`(1전 다이가와 다른 그림).
- 기록 방법상 주의: VRAM 스프라이트 표는 1프레임 늦게 화면에 반영된다(켜진 첫 프레임에 오버레이 없음·꺼진 첫 프레임에 직전 오버레이 남음). 기록기는 그림 이름표를 직전 프레임 상태로 단다.
- 시트에 없는 것: 3전 승리 후 팀 그림, 15전 승리 후 엄마 그림, 맞대면(서브 7) 화면 배치.
