# 11. 조작 선수 자동 전환(외야 포함)과 공 줍기

표기: [확인]=ROM 코드 판독 + 에뮬레이터 실측 일치 / [추정]. 실측: `analysis/state/ctrl0.pkl` 에서 공(0xC700)을 정지 공(타입 0x1C, 서브4, 타이머 30)으로 직접 배치하고 프레임 실행, 사이드 구조 $E700/$E780 의 +$18(조작 선수)·+$5D(공 구역) 관찰.

## 1. 공 구역 판정 (0x6F5C → 0x6DB8, 표 0x6B74=좌석0 / 0x6BDC=좌석1) [확인]
- 정지 후 30f 마다(0xA640) 0x6F5C 가 각 사이드의 $5D(공 구역=슬롯 시작 번호)를 갱신: 0=내야, 4=외야 상단(슬롯4~6), 7=외야 하단(7~9), 10=외야 후방(10~12), -1=어느 구역도 아님. 0x6DB8 은 공 히트박스(표 0x69D8 idx1: x±8, y±4)와 구역 사각형의 겹침 검사.
- 좌석0 구역(x0,x1,y0,y1): 내야 88~256 × 32~224, 상단 256~444 × 16~32, 하단 256~444 × 224~255, 후방 424~444 × 32~224. 좌석1 은 x 를 512-x 로 반전. 0x6F26~ 은 y/4 만큼 x 경계를 기울이는 사다리꼴 보정(웹은 생략 [추정]).
- 즉 외야 선수는 **상대 코트 바깥 띠**에 서며, 그 띠에 공이 멈추면 그 팀(좌석)의 외야 구역이 된다. 좌석0 이 (350,25)에 멈춘 공 → 좌석0 의 상단 외야(슬롯4)의 구역.
- 어느 구역도 아니면 -1: 내야 최근접으로 전환. 좌측 코트 밖 등 양쪽 모두 -1 이고 x≤0x100 이면 상대(좌석1) $5D=0xD → 0x8622 가 후방 외야를 공 회수에 투입(타입 0x44) [확인 관측: (20,128) 공을 후방 외야가 집어 던짐; 웹 미구현].

## 2. 전환 규칙 (0x85CC → 0x8660 → 0x85EE/0x8752 → 0x88B8) [확인]
- 공이 정지(서브4)한 뒤 **29~30f 후 첫 전환, 이후 30f 마다**. 실측: 정지 배치 후 f29 에 ctrl 변경.
- 건너뛰는 조건(0x8660): 사람 사이드이고, 현재 조작 선수 슬롯<4(내야)이며, $5D 가 0~3(내야 구역), 방향키 하위 4비트≠0 일 때만. 따라서 **공이 외야 구역($5D≥4)이면 방향키를 눌러도 전환**, 조작 선수가 외야(슬롯≥4)여도 전환(내야로 복귀).
- 후보(0x8752): $5D=0 또는 -1 → 슬롯0~3 중, $5D=4/7/10 → 슬롯 $5D~$5D+2(외야 해당 구역) 중 죽지 않은($1E=0) 선수 가운데 공과 거리 최소(0x8720, 0x2254/0x22A8 근사 거리). 내야·외야를 섞어 비교하지 않고 구역 하나로 한정.
- 실측: 공(350,25)→ctrl 0xC200(슬롯4), (340,239)→0xC280(슬롯7), (470,128)→0xC300(슬롯10), (150,128)·(100,128)→내야 0xC080(슬롯1), (200,128)→변동 없음(0xC000 가 최근접).
- 전환 후 0x88B8: 구 조작 선수는 0x821C(사람→CPU 형), 신규는 0x8262(→조작 형, 외야는 타입 0x34/0x38).

## 3. 줍기 [확인 실측]
- **사람 조작 선수는 정지한 공을 자동으로 줍지 않는다.** 공이 조작 선수 바로 위(거리 0)여도 240f 동안 줍지 않음. **A 키**를 누르면 줍기 모션(약 15f, 실측 f15 에 보유)을 거쳐 습득.
- A 습득 반경(조작 선수 기준): 내야 x ±20(24은 실패), y ±20(24 실패); 외야 상단 x ±22(24 실패)·y ±12(16은 실패, 공이 구역 밖), 외야 하단 x ±20·y ±16, 외야 후방 x ±22·y ±20.
- CPU 선수는 자기 구역 공을 스스로 걸어가 줍는다(타입 0x70 두뇌, 자동). 사람 사이드의 비조작 선수도 CPU 형이다.
- 외야 선수 조작 중 입력: 방향키는 한 축만(상단/하단=좌우, 후방=상하) [05 문서 §0x82A4/0x82D6 확인], A=줍기/패스, B=투구. 투구 가능(외야 투구는 일반만, 필살 불가).

## 4. 웹 반영 (server/engine/match.js, server/data/rules.json `ctrlSwitch`·`autoPickup.human`)
- `ballZone(seat)`: 위 구역 사각형 판정(데이터화). `autoSwitch`: 정지 공이 외야 구역이면 30f 주기로 해당 구역 외야 최근접 선수로 전환(방향키 무관).
- `settleBall`: 외야 구역에 놓인 공은 코트 안으로 옮기지 않음(종전 [추정] 이동이 외야 전환을 막던 원인).
- `autoPickup`: 사람이 조작 중인 선수는 제외(A 로만 줍기).
- 미구현/[추정]: 사다리꼴 보정, 양쪽 -1 구역에서 후방 외야 회수(0x8622), 비조작 CPU 외야의 자동 습득 반경(웹은 12px 유지; 후방 외야는 공이 최대 20px 떨어질 수 있어 못 줍는 경우 가능), 외야 A 반경은 웹이 기존 catch 히트박스 기준.
