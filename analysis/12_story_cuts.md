# 12. 스토리 모드 진입 내레이션 컷

표기: [확정] = 자작 에뮬레이터 실행 + 렌더 PNG 육안 판독, [추정] = 정황·규칙 외삽. 소리는 청취하지 않음(UNVERIFIED).

## 위치 [확정]
- 부팅 오프닝(10_intro_title.md)에는 내레이션이 없다. 사용자 스크린샷(번개 바다·깃발 둥근 물체, 실루엣, 두 소년, 'そのしょうねんの いしをなげる…')은 **스토리 모드 진입 컷 3번째**다.
- 진입: 모드 메뉴($E600=0x8C)에서 '倒せ!闘球の強豪たち' START → 서브메뉴 'はじめから/つづきから' START → 상태 0x9C(컷 재생, 모드 메뉴 도달 기준 f55~) → 컷 4장 후 상태 0x28(제목 카드 '第1戦 「大河への挑戦」') → 0x14(팀 비교·포메이션) → 경기.
- 컷 사이 B/C 버튼으로 페이지를 넘길 수 있다(무입력이면 자동 진행). 그림 영역: 화면 (32,32) 256x96, 글자: y≈139~165 흰색 2줄, 검정 배경.

## 이름·글자 근거
- 'にかいどうたいが' 글자 [확정](컷 4 화면 판독 + 팀 소개 화면 라인업에 二階堂大河·五十嵐剛, 09_team_names.md 팀1). 'セントアローズ' = 팀1 상아 [확정](팀 소개 화면 팀명). 'たまがわしょう' = 팀0(태동) [확정].
- 한국어 '남타이거' 대응은 names_ko.md 자체가 불확실([B]에 일본명 미기재) → **미해결**(ROM 에는 한국 이름이 없음, 번역판 근거 필요). 화면 문구는 그대로 두되 미해결 표시.
- 'いちねんせい'(1학년): 글자는 5배 확대 판독 [확정], ROM 내 다른 문자열로 교차 검증할 수 없고 원작 설정(보통 고학년)과 다를 수 있음 → **미해결**(원작 영상 대조 필요).

## 구현·데이터
- 그림 `public/assets/rom/story/cut_1~4.png`(256x96, ROM 렌더 크롭), 데이터 `public/assets/rom/story/story_cuts.json`(일본어 원문·한국어·타이밍·근거, manifest 미사용), 모듈 `public/js/story_cut.js`.
- 호출: 스토리 경기 1 시작 시 최초 1회(localStorage `dd.storyCutSeen`) 자동 재생, 스토리 목록 '프롤로그' 버튼, 로비 '오프닝 다시보기'(부팅 인트로 재생). BGM 미연결(데이터에 키 `bgm.story_cut`만, 키가 manifest 에 있을 때만 재생하도록 확장 가능).
- 스크립트: `t_story_rec.py`(VDP 기록), `t_story_sheet.py`(몽타주), `t_story_skip.py`(버튼 진행 PNG 캡처), `t_story_probe.py`, `t_story_pages.py`. 상태 pkl 은 analysis/state/story_rec*.pkl(다시 만들면 ROM 속도상 수십 분).

## 오프닝이 '안 보인' 원인 [코드·브라우저 확인]
- 새 브라우저 프로필 첫 접속에서는 부팅 인트로가 재생된다(headless 확인, 4초 시점 f≈500~570). `dd.introSeen`(sessionStorage) 때문에 같은 탭 재방문·새로고침은 생략된다. 사용자가 본 오프닝이 '영상 속 컷'(스토리 진입 컷)이라면 구현 자체가 없었던 것이다.
