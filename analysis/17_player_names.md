# 17. 선수 이름(한국판) 정리·작명안

산출: `analysis/data/player_names_ko.json` (소스 미적용 제안안). 근거 수준: 확인 / 추정 / verify(=확인 필요, 신규 작명 포함).
이름 값에는 근거 표기가 없고, 근거는 JSON `details[].ev` 와 이 문서에만 있다.

## 1. 원인 진단: 번호 표시는 "데이터 누락"이 아니라 "한글 필터"
- 선수 이름 데이터는 비어 있지 않다. `public/assets/data/team_names.json` 의 teams[].players 에 25팀 x 7명 전원이 들어 있다. 다만 값이 (a) 확정 한국판 이름 또는 (b) 원작 일본어 표기(히라가나·가타카나)다.
- UI 위치: `public/js/pix.js` 45행 `n && /[가-힣]/.test(n) ? n : \`${i+1}번\``. 한글이 없으면 번호로 대체한다. 즉 일본어 표기 선수는 전부 'N번'이 된다. `names.js` teamPlayers 는 정상적으로 읽고 있다.
- 암산 국민학교(team 2)는 7명 중 일본어 7명이 그대로 들어 있어 전원 1~7번. 원인: team_names.json 작성 시 "[확인]된 한국판 이름만 쓴다"는 규칙으로 [추정]인 태백산(idx0), 강민철(idx6)도 제외했다(`analysis/teams_names.json` 에는 둘 다 name_ko 있음, 근거 '추정').
- 번호가 보이는 선수 수(현 데이터 기준): 팀0·22 0명, 팀1 5명, 팀2 7명, 팀3 5명, 팀4~21 전원(7x18=126), 팀23 7명, 팀24 2명(れんしゅう1·2). 합 약 159명.

## 4. 작명 규칙
- 한글 2~4자(HUD 폭), 외국 이름은 이름만 또는 성만. 팀 내 중복 없음, 전체 중복은 팀15/23 의도적 동일 외 없음.
- 일본 4~7: ROM 일본어 이름을 한글로 음차한 짧은 형태. 팀1~3 은 한국판 현지화 전례(장도끼·우갑철 등)에 맞춘 한국식 이름(원명 한자 의미를 살짝 차용).
- 해외팀: ROM 원작 표기를 바탕으로 한 국적별 이름. 실존 유명인(クルシチョフ→크루닌, スターリア→세르게이 등)·신 이름(ゼウス 등, 현대 그리스 이름으로 대체)·인사말(ニーハオ)·별명 비하 소지(シャオパン) 회피.
- 에이스(idx0 주장급·능력치 상위: 팀4 하야토, 팀8 줄리안, 팀10 밍하오 등)에게 짧고 강한 이름 배정. 초상 확인 후 외형과 어긋나는 이름은 교체(예: 팀8 데인저→맥스).
