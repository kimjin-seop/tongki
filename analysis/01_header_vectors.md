# 01. ROM 헤더 / 벡터 / 체크섬 / 엔트리

자동 생성: `analysis/scripts/rom_header.py` (ROM 크기 524288 바이트 = 0x80000)

## 헤더 (0x100-0x1FF)

- `0x100` 시스템 타입: `SEGA_MEGA_DRIVE`
- `0x110` 저작권/날짜: `(C)SEGA_1992.APR`
- `0x120` 국내명(일본어): `炎の闘球児　ドッジ弾平`
- `0x150` 해외명: ``
- `0x180` 시리얼/버전: `GM_00004076-00`
- `0x18E` 체크섬(헤더): 0xBACC
- `0x190` 지원 디바이스: `J`
- `0x1A0` ROM 범위: 0x0 - 0x7FFFF
- `0x1A8` RAM 범위: 0xFF0000 - 0xFFFFFF
- `0x1B0` 외부 메모리 헤더: `52 41 e8 40 00 20 00 01 00 20 00 01` = RA  (-> 'RA' + 0xE840 + 0x200001..0x200001 ; 0xE840 은 **EEPROM** 타입 표기. 코드 0x152BC 가 $200001 의 bit0/bit1 을 SCL/SDA 로 비트뱅잉(확인) = X24C01 계열 직렬 EEPROM 세이브)
- `0x1F0` 지역: `J`

## 체크섬

- 0x200 이후 워드 합 = 0xBACC, 헤더 값 0xBACC -> **일치**.
- 부팅 코드(0x32C-0x358)가 실제로 이 체크섬을 계산해 비교하며, 불일치 시 0x490(화면을 단색으로 채우고 무한 루프)으로 분기.

## 벡터 테이블 (0x000-0x0FF)

| idx | 주소 | 이름 | 값 |
|---|---|---|---|
| 0 | 0x000 | SSP(초기 스택) | 0xFFFF70 |
| 1 | 0x004 | Reset(PC) | 0x000206 |
| 28 | 0x070 | Level4 (HBlank) | 0x000200 |
| 30 | 0x078 | Level6 (VBlank) | 0x000914 |

나머지 벡터는 모두 0x200 (`nop; nop; bra.b $200` 무한 루프 = 사실상 정지)으로 채워져 있음.

- Reset PC = **0x000206** (헤더 뒤 표준 SEGA 초기화: TMSS 'SEGA' 기록, Z80 리셋, VDP/PSG 초기화 테이블 0x294~, 0x300으로 점프).
- VBlank = 0x000914, HBlank = 0x000200(정지 루프; SR=0x2500으로 마스크되어 실제 발생하지 않음).
- 부팅 후 메인 엔트리: 0x300 -> (VDP 대기, 체크섬 검증, 콘솔/패드 포트 초기화, RAM 0xFF0000-0xFFFFFF 클리어, 'init' 마커($FFFC) 검사, 팀/AI 테이블 ROM->RAM 복사) -> 0x3EA 이후 게임 초기화 -> **메인 루프 0x458**.
